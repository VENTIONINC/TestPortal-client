# Contributing

Thanks for contributing to Test Portal Client. This guide keeps the expected
workflow lightweight and predictable.

## Contribution Flow

1. Start with an issue, discussion, or approved OpenSpec change when the work
   affects behavior, architecture, or contributor workflow.
2. Create a focused branch from `main`.
3. Make the change, update docs when needed, and keep generated output in sync.
4. Run the local validation commands before opening a pull request.
5. Open the pull request with a short explanation of what changed and why.

## Local Development

1. Install dependencies with `yarn install`.
2. Create a local `.env` file based on `.env.example`.
3. Start the development server with `yarn dev`.
4. Run `yarn generate-api` or `yarn generate-mcp-api` when API schema changes
   require regenerated client types. To regenerate the main API from the local
   backend, run `RTK_QUERY_OPENAPI_URL=http://localhost:3001/api/openapi.json yarn generate-api`.
5. Use `yarn new:file -- <path>` when creating a new supported source file so
   the standard Apache 2.0 header is added automatically.
6. Use `yarn headers:add` to backfill the standard header across supported
   existing source files in `src`. Existing legacy Apache 2.0 source headers
   are normalized to the root `NOTICE` copyright owner.

Supported file types for `yarn new:file`:

- `.ts`
- `.tsx`
- `.js`
- `.jsx`
- `.mjs`
- `.cjs`

Unsupported extensions fail with a clear error that lists the supported
extension set. For file formats such as Markdown, JSON, CSS, images, and other
assets, create the file manually until explicit support is added.

## Generated API Output

`src/redux/apis/generatedApi.ts` is generated by RTK Query codegen and is
excluded from `yarn headers:add`. Regenerate it with `yarn generate-api` or
`yarn generate-mcp-api` as needed, but do not rely on the bulk header command
to modify that generated file.

## Validation

Before opening a pull request, run:

1. `yarn lint`
2. `yarn build`

Add any task-specific checks that are relevant to your change.
