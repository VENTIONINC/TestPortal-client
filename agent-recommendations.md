# Agent Recommendations for Test Portal Client

**Frontend Development Agents:**

- **react-component-creator** - Creates new React components following the established feature domain organization and TypeScript patterns
- **redux-toolkit-helper** - Manages RTK Query API slices, Redux state, and handles the dual API configuration (baseApi/mcpApi)
- ✅ **chakra-ui-designer** - Builds UI components using Chakra UI v3 patterns, handles theming and dark mode implementations
- **typescript-refactor** - Performs type-safe refactoring, interface updates, and maintains TypeScript code quality

**API & Code Generation Agents:**

- **openapi-codegen-manager** - Manages API code generation workflows, updates generated types after schema changes
- ✅ **api-integration-specialist** - Handles RTK Query endpoint creation, caching strategies, and authentication flow integration

**Testing & Quality Agents:**

- **test-writer** - Creates Jest/React Testing Library tests for components and Redux logic
- **code-reviewer** - Reviews code for TypeScript best practices, React patterns, and architectural consistency

**Workflow & Maintenance Agents:**

- **vite-build-optimizer** - Manages Vite configuration, build optimization, and development server setup
- **dependency-updater** - Handles package updates while ensuring compatibility with the RTK Query + Chakra UI stack
